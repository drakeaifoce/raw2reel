# ai

Python-сервис: выстраивает порядок вызовов внешних Muse-пайплайнов и готовит
изображения. Локальных моделей не держит — GPU на этой подписке недоступен,
квота у всех GPU-семейств 0/0 и не повышается, так что всё считается на CPU.

Сейчас это каркас: конфигурация, предобработка изображений, проверки
готовности и тесты. Самих пайплайнов пока нет.

## Стек

Python 3.12, FastAPI, uvicorn. Зависимости через `uv` с `uv.lock`. Pillow для
изображений, `pymongo` и `azure-storage-blob` для БД и файлов. Линтер — ruff,
он же форматтер.

## Запуск

```bash
cd ai
uv sync
cp ../.env.example .env   # заполнить значения
uv run uvicorn raw2reel_ai.main:app --reload
```

## Команды

- `uv run pytest -q` — тесты
- `uv run ruff check .` — линтер
- `uv run ruff format --check .` — форматирование, как в CI

## Про память

`MAX_IMAGE_PIXELS` ограничивает распаковку входящего изображения жёстко, а не
предупреждением, как Pillow делает по умолчанию. Хост делит 4 GB между всеми
сервисами, и одна «бомба» в ответе от пользователя уронила бы заодно бэкенд и
Gitea, которая выполняет деплой.

Контейнеру в compose выставлен лимит 640 MB — самый большой из трёх сервисов,
потому что предобработка изображений жаднее остальных.
