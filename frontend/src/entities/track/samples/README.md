# Sample tracks

Drop audio files here (`.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg`, `.flac`). The build picks
them up automatically and lists them as soundtrack presets, sorted by file name.

The file name sets what the studio shows:

```
Title - Mood - BPM.mp3
```

- `Phonk drive - Hard-hitting - 140.mp3` → **Phonk drive**, Hard-hitting · 140 BPM
- `Sunny pop - Upbeat.mp3` → **Sunny pop**, Upbeat
- `Night ride.mp3` → **Night ride**, Sample

Mood and BPM are optional; `140bpm` works too. Keep each file under 100 MB, the media
upload limit: a preset is uploaded to the user's media when picked, so the renderer can
mix it in.

While this folder has no audio, the studio shows placeholder presets without music.
